# 09 — Templates and error handling

Topics: function/class templates, specialization basics, type deduction, concepts, exceptions, standard error types, and choosing between exceptions and explicit error values. `std::expected` is available in C++23 implementations.

## Exercises
- Implement a templated `clamp` or `minimum`.
- Constrain a template with a C++20 concept.
- Write a parser that reports malformed input without crashing.
- Document which functions can throw and what callers should expect.
