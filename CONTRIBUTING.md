# Contributing

- Use descriptive names and document each topic with a short explanation.
- Prefer portable C++20 unless a platform-specific example is clearly labeled.
- Compile with `-Wall -Wextra -Wpedantic` on GCC/Clang.
- Add tests for reusable logic and update documentation.
- Avoid undefined behavior, unnecessary raw owning pointers, and unexplained cleverness.
- Do not commit build directories, generated binaries, secrets, or personal data.
- Keep pull requests focused and explain what changed and why.
