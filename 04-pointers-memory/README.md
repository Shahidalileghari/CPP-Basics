# 04 — Pointers and memory

Learn addresses, pointers, references, `nullptr`, object lifetime, stack versus dynamic storage, pointer constness, and dangling-pointer errors.

Understand raw pointers, but prefer values and standard-library ownership types in ordinary code. Never return pointers or references to local variables.

## Exercises
- Swap two integers using references.
- Explain `const int*` versus `int* const`.
- Demonstrate why a pointer can dangle after object lifetime ends.
- Replace a manual dynamic array with `std::vector`.
