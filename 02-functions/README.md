# 02 — Functions

Study declarations and definitions, return types, parameters, pass-by-value, pass-by-reference, `const` references, scope, overloads, default arguments, and recursion.

## Exercises
- Write `is_prime`, `gcd`, and `factorial` with documented input constraints.
- Compare pass-by-value and pass-by-const-reference.
- Overload a function for integers and floating-point numbers.
- Implement binary search and state its complexity.
