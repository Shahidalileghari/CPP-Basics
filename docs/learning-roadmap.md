# Learning roadmap

## Beginner: reason about code
Master expressions, control flow, functions, collections, input validation, and basic debugging. Write small programs without copying complete solutions.

## Intermediate: write maintainable programs
Learn OOP, STL, algorithms, exceptions, file I/O, tests, and CMake. Build at least two projects with persistent data and documented interfaces.

## Advanced: understand behavior and trade-offs
Study RAII, move semantics, templates, concepts, concurrency, complexity, profiling, and portability. Read compiler diagnostics and use sanitizers.

## Suggested weekly rhythm
- 3 sessions: learn and implement one topic.
- 2 sessions: solve exercises and edge cases.
- 1 session: review, test, refactor, and write notes.
- 1 session: rest or revisit difficult concepts.

Progress is demonstrated by understanding and working code, not simply finishing folders.
