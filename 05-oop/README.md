# 05 — Object-oriented programming

Topics: classes and objects, access control, constructors/destructors, invariants, composition, inheritance, virtual functions, abstract interfaces, operator overloading, and the rule of zero/five.

## Exercises
- Implement a `BankAccount` with validated deposits and withdrawals.
- Model a library using composition.
- Create an abstract `Shape` interface and derived shapes.
- Explain when composition is preferable to inheritance.
