# 03 — Collections and strings

Learn built-in arrays, `std::array`, `std::vector`, `std::string`, iteration, bounds, and standard algorithms. Prefer standard containers for ordinary application code.

## Exercises
- Find minimum, maximum, and average of a vector.
- Remove duplicates while preserving order.
- Count words and character frequencies in a string.
- Rotate a vector by K positions.
- Compare a manual loop with `std::sort`.
