# 01 — Fundamentals

Learn compilation, `main`, variables, primitive types, `const`, type conversion, console I/O, operators, conditions, switches, loops, and compiler diagnostics.

## Exercises
1. Print your name and introduction.
2. Read two numbers and print arithmetic operations; handle division by zero.
3. Convert Celsius to Fahrenheit.
4. Determine whether a number is even or odd.
5. Print a multiplication table.
6. Calculate the sum from 1 through N without overflowing for the chosen range.

Start with `hello_world.cpp`, then solve `exercises.cpp`.
