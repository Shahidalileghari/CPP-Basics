# 06 — Standard Template Library

Learn `vector`, `array`, `deque`, `list`, `stack`, `queue`, `priority_queue`, `set`, `map`, unordered containers, iterators, algorithms, lambdas, and ranges.

## Exercises
- Count frequencies with `std::unordered_map`.
- Use `std::priority_queue` to find the K largest values.
- Sort records with a lambda comparator.
- Explain iterator invalidation for vector and unordered containers.
- Use `std::find_if`, `std::transform`, and `std::accumulate`.
