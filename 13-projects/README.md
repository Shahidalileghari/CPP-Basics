# 13 — Projects

Keep each project in its own folder with a README, build instructions, tests, and examples.

## Beginner
- Calculator with validated input
- Number guessing game
- Unit converter
- Quiz application

## Intermediate
- Contact manager with file persistence
- Inventory manager
- Text file statistics tool
- Library management system
- Expense tracker with categories and CSV export

## Advanced
- Command-line task manager with search and persistence
- Log analyzer with filters and summary reports
- Thread-pool task executor
- HTTP client using a maintained library
- Graph algorithms toolkit with benchmarks

## Capstone: CLI Expense Tracker
- Add, list, edit, and delete expenses.
- Validate amounts, dates, and categories.
- Persist records to CSV or JSON.
- Filter by date/category and calculate totals.
- Separate domain logic from input/output.
- Add unit tests and clear error messages.
- Build with CMake and document usage.

Stretch goals: SQLite storage, import/export, CI, and release binaries.
