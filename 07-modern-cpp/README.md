# 07 — Modern C++

Learn `auto`, range-based loops, uniform initialization, structured bindings, `enum class`, `constexpr`, `noexcept`, `std::optional`, `std::variant`, `std::string_view`, and C++20 concepts and ranges.

## Exercises
- Replace repeated iterator boilerplate with algorithms.
- Return `std::optional` when a lookup may have no result.
- Use `std::variant` to model a value with several possible types.
- Add `const`, `constexpr`, and `[[nodiscard]]` where they express intent.
