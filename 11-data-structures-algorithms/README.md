# 11 — Data structures and algorithms

Study Big-O time/space complexity, arrays, linked lists, stacks, queues, hash tables, binary search trees, heaps, graphs, recursion, divide and conquer, greedy algorithms, backtracking, and dynamic programming.

## Practice sequence
1. Linear search and binary search.
2. Bubble, insertion, merge, and quick sort; compare complexity and stability.
3. Stack, queue, and linked-list operations.
4. Hash-map frequency problems and two-sum.
5. Tree traversals and binary search tree operations.
6. BFS, DFS, shortest paths, and graph representations.
7. Recursion, memoization, tabulation, and common DP patterns.

For every solution, document assumptions, edge cases, time complexity, and space complexity.
